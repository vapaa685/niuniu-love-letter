# 文文 ♡ 牛牛 · 一封小情书

粉白色、适配手机的个人告白网页。原生 HTML / CSS / JavaScript，无需安装依赖或构建。

## 内容与互动

- 文文写给牛牛的短情书，支持弹窗拆信与 Escape 关闭。
- 本地 SVG Hello Kitty、大耳狗插画，信封漂浮、滚动渐入、爱心粒子。
- 「文文想问：你最喜欢谁了」小考卷，四个选项完整保留。
- 首次选 A/B/C：`嘻嘻，寒假等着被我狠狠奖励吧`。
- 首次选 D：`行，寒假等着被我狠狠惩罚吧`，出现「再做一次」。
- 重做继续选 D：`惩罚时间×2`、`惩罚时间×3`……依次累加。
- 选过 D 后重做选 A/B/C：`骗牛牛的，选对了我也惩罚你，嘻嘻`。
- 点击亲亲按钮出现爱心，计数保存在当前浏览器。答题进度刷新后重置。
- 点击顶部音乐开关播放 Web Audio 合成的轻柔原创旋律；默认关闭。
- 支持系统减少动态效果设置和键盘操作。

## 本地查看

在本目录运行：

```sh
python -m http.server 4173
```

打开 http://localhost:4173 。也可以直接用浏览器打开 `index.html`。

## 文件

- `index.html`：文案与网页结构。
- `style.css`：颜色、排版、响应式布局与动画。
- `app.js`：小考卷逻辑、拆信、亲亲计数、音乐。
- `assets/`：本地 SVG 插画和图标，不依赖外链图片。

## GitHub Pages

发布设置：从 `main` 分支的根目录发布，`.nojekyll` 关闭 Jekyll 处理。所有资源使用相对路径，可部署到 GitHub Pages 的项目子目录。
